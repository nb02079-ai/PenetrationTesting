## Purple 분석 (핵심 서사)
WAF가 **잡는 공격(CASE 2 업로드 페이로드)** 과 **못 잡는 공격(CASE 1 BOLA·CASE 3 계정관리)** 의 대조.
→ 경계 방어(WAF)만으로는 불충분하며, **애플리케이션 로직·계정 수명주기 관리·SIEM(auditd/앱로그)** 이 함께 작동해야 함.
