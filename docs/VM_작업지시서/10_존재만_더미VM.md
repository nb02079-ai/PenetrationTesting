# LOGION '존재만' 더미 VM 안내 (운영자·Samba·직원PC·협력업체·Syslog·NTP)

- **상태**: 구성도에만 표시, 평소 **VM 꺼둠**. CASE에 직접 안 쓰이면 엔드포인트만 존재.
- 자원 절약을 위해 통합테스트·해당 시나리오 때만 선택적으로 켬.

## 제안 IP (팀 최종표로 치환)
| VM | 내부망 | IP | GW | 비고 |
|---|---|---|---|---|
| 운영자 서버 | `LOGION-srv` | 10.10.20.20/24 | 10.10.20.1 | 관리용 웹(선택) |
| Samba | `LOGION-srv` | 10.10.20.30/24 | 10.10.20.1 | 사내 공유폴더. CASE 3에서 접근 대상이면 실제 구현 |
| 직원PC | `LOGION-office` | 10.10.30.10/24 | 10.10.30.1 | 평소 업무용 |
| 협력업체 계정 | `LOGION-office` | 10.10.30.20/24 | 10.10.30.1 | **CASE 3 출발점** — 실제로 쓰면 OS 계정/SSH 필요 |
| Syslog | `LOGION-soc` | 10.10.40.110/24 | 없음 | 로그 집계(선택) |
| NTP | `LOGION-soc` | 10.10.40.120/24 | 없음 | 시간 동기(선택) |

## 참고
- **협력업체 계정**은 CASE 3의 시작점이라, 이 시나리오를 돌릴 거면 '존재만'이 아니라 **실제 로그인 가능한 VM**으로 올려야 함(office→Bastion SSH).
- 나머지는 구성도 완성도·확장용. 빌드 우선순위는 낮음.
